
# FinTrack Pro

FinTrack Pro is a Personal Finance and Expense Management System developed using Python and Gradio.

## Features
- Add and manage transactions
- Track income and expenses
- View financial summaries
- Visualize spending through charts
- Search and filter transaction history
- Export transaction data to CSV and Excel

## Technologies Used
- Python
- Gradio
- Pandas
- Matplotlib
- OpenPyXL

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the application:

python app.py
